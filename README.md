One micro-confession in exactly two parts — a To: line and the unsent message itself, typed and never sent: she knew her best friend liked him first, said yes anyway, and has rehearsed the apology a hundred times without it ever sounding like enough.

## The confession

> To: my best friend since school
> i knew you liked him first and i still said yes when he asked me out. ive rehearsed this apology a hundred times and it never sounds like enough

The reason it stayed in drafts is felt, not stated: a hundred rehearsals, and the apology never sounds like enough. The To: line and the message need each other — "you liked him first" only lands because the addressee is the best friend since school. Lowercase throughout, "ive" with no apostrophe: a draft thumb-typed and abandoned, not a line written to be sent.

## Run it

```sh
python3 main.py
```

This writes the confession to `/output/entry.txt` (176 characters, UTF-8, deterministic — repeated runs produce byte-identical output). The message line is 144 characters, inside the 200-character limit; the whole file is inside the 260-character gate.
